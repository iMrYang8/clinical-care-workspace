Nightingale attribution
=======================

This repository began as an adaptation of the FastAPI Full Stack FastAPI
Template at upstream commit 68adb40d:
https://github.com/fastapi/full-stack-fastapi-template/commit/68adb40d

Upstream copyright: Copyright (c) 2019 Sebastián Ramírez and FastAPI
contributors.
Upstream license: MIT. The MIT license text is retained in LICENSE.

The Nightingale name and the baseline configuration changes in this repository
do not remove the upstream attribution or its MIT notice.

The care-note editor directly uses the MIT-licensed Tiptap open-source packages
at version 3.30.3 and the MIT-licensed Serene in Serenade Tiptap Comment
Extension at version 0.2.0:
https://github.com/ueberdosis/tiptap
https://github.com/sereneinserenade/tiptap-comment-extension

The third-party comment extension is isolated behind Nightingale's
CommentAnchorAdapter. No extension source is vendored or modified in this
repository.

The voice capture queue directly uses idb 8.0.3 under the ISC license. The
test-only fake-indexeddb 6.2.5 package is Apache-2.0. FFmpeg is installed as a
separate executable in the backend container and records the exact distributed
build configuration in /usr/share/doc/nightingale/ffmpeg-build.txt.

Encrypted archive payloads directly use zstandard 0.25.0 under the BSD
3-Clause license. The package is resolved from the backend dependency lock;
the project does not vendor its source.

The optional, explicitly gated OpenAI Realtime transcription transport directly
uses websockets 16.0 under the BSD 3-Clause license. No OpenAI model weights or
API responses are bundled with this repository.

Clinic-level OpenAI model identifiers and encrypted API-key storage are
Nightingale configuration features. They do not bundle OpenAI weights,
credentials, or provider responses. The committed fact and voice calibration
JSON files contain repository-authored derived metrics plus selected binding
fields (provider, exact model, task, evaluation-manifest hash, sample counts,
and result band) from mock/synthetic inputs; they contain no API key, raw
provider response, or patient data. They do not contain a complete provider
request/response record. Model names in those reports identify the evaluated
service configuration and do not imply clinical validation.

The optional local evaluation importer downloads but does not commit three
pinned synthetic/mock datasets:

* MITRE Synthea sample data, sample repository commit
  9959d9178ea28f4ec10f17ee238b6fabe6eb0de5. The Synthea generator is
  Apache-2.0 and its generated records are described as free of patient privacy
  restrictions: https://github.com/synthetichealth/synthea-sample-data
* ACI-Bench, Figshare file 41498793, CC BY 4.0. Cite Yim et al., "Aci-bench:
  a novel ambient clinical intelligence dataset for benchmarking automatic
  visit note generation", Scientific Data (2023):
  https://doi.org/10.1038/s41597-023-02487-3
* PriMock57, repository commit
  cd2ac707ad03cb4d2531f4ec6b90c659bf4357c5, CC BY 4.0. Cite Papadopoulos
  Korfiatis et al., "PriMock57: A Dataset Of Primary Care Mock
  Consultations", ACL 2022: https://doi.org/10.48550/arXiv.2204.00333

The raw archives and audio remain Git-ignored. Imported rows are transformed,
encrypted, source-labelled evaluation fixtures. The applicable CC BY 4.0 and
Synthea Apache-2.0 texts are retained under THIRD_PARTY_LICENSES/.
Derived evaluation metrics and calibration metadata are authored by this
repository; the upstream dataset licenses and citation requirements continue
to govern the source data from which those metrics were computed.

The release-document builder uses ReportLab 4.4.9 under the BSD license. Its
license is retained in THIRD_PARTY_LICENSES/ReportLab-BSD.txt. The builder calls
the operator-provided rsvg-convert executable from librsvg to rasterize the
checked-in diagrams; librsvg is a build prerequisite and is not bundled here.

THIRD_PARTY_NOTICES.md records direct dependencies, planned integrations, and
design references. Entries marked planned, optional, or design reference are
not bundled dependencies, vendored source, or shipped assets in this baseline.
