# Nightingale evaluation datasets

Nightingale keeps external dataset payloads out of Git. The tracked manifest in
`manifests/evaluation-pack-v1.json` pins the official source, version, license,
and SHA-256 for every downloaded artifact. Run:

```bash
python3 scripts/download_test_datasets.py
./scripts/import-test-datasets.sh
```

The default pack imports at most 20 Synthea patients, 10 ACI-Bench encounters,
and 5 PriMock57 consultations. Only the first PriMock57 consultation includes
the two original audio tracks; the other four import transcript and reference
note data. Raw archives and audio are written to `datasets/raw/`, which is
ignored by Git.

Imported records are synthetic benchmark material, not model output and not
clinical validation. Stable UUIDv5 identifiers make re-import idempotent.
`DomainEvent` rows retain dataset/version/source-record/checksum metadata without
placing raw clinical text in audit logs.

## Sources and permitted use

- **Synthea sample data** — generated by MITRE Synthea. The generator is
  Apache-2.0 and Synthea describes its output as synthetic records free of
  patient privacy restrictions; this repository does not imply a broader
  license grant for third-party material.
- **ACI-Bench** — synthetic clinical dialogue/note corpus, CC BY 4.0. Cite the
  Scientific Data paper when using any subset.
- **PriMock57** — mock primary-care audio/transcript/note corpus, CC BY 4.0.
  Attribution is required for redistributed subsets and adaptations.

See `ATTRIBUTION.txt`, `THIRD_PARTY_NOTICES.md`, and the manifest for exact URLs
and pinned revisions.
